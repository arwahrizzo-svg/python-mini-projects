## 🚀 Existing Projects

### 1. Digital Clock
A minimal, high-contrast digital clock displaying real-time hours, minutes, and seconds in a 12-hour format with an AM/PM indicator.

* **Tech Stack:** Python, PyQt5 (GUI)
* **Key Features:** Real-time updates using `QTimer`, retro custom typography, and CSS-based layout styling.
* **Prerequisites:**
  ```bash
  pip install PyQt5
  ```
  *(Note: Requires the `DS-DIGIT.TTF` font file in the directory to display the digital font properly).*

### 2. WiFi QR Code Generator
An automation script I wrote that generates a scannable QR code containing WiFi credentials, allowing guests to connect to a local network instantly without typing a password.

* **Tech Stack:** Python, `qrcode` library
* **Key Features:** Clean image output, lightweight processing, and seamless cross-platform scanning.
* **Prerequisites:**
  ```bash
  pip install qrcode[pillow]
  ```

## 🛠️ How to Run Any Project

1. Clone my repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the repository folder:
   ```bash
   cd python-mini-projects
   ```
3. Install the required modules as noted in the project descriptions above, then run the script of your choice:
   ```bash
   python "WiFi Qrcode.py"
   ```
